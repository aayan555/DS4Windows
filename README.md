## Overview
**DS4Windows** is a popular, free, and open-source tool that allows you to use your **PlayStation DualShock 4** and **DualSense** controllers on PC with full functionality.

It emulates an Xbox 360 / Xbox One controller, provides advanced features, custom profiles, and excellent low-latency performance for gaming.

## Key Features
- Full DualShock 4 & DualSense support (including gyro, touchpad, adaptive triggers)
- Emulates Xbox 360 / Xbox One controller
- Highly customizable button mapping & profiles
- Motion controls (Gyro) support
- Low latency mode
- Battery level indicator
- LED customization
- Multiple controller support
- Auto profile switching per game
- HidHide & ViGEm integration

## How to Use
1. Download the latest release
2. Extract the archive
3. Run `DS4Windows.exe` as Administrator
4. Connect your controller via Bluetooth or USB
5. Enjoy playing with full support

## Supported Controllers
- DualShock 4 (PS4)
- DualSense (PS5)
- DualSense Edge
- Other PlayStation controllers
